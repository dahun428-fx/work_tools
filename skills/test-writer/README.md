# test-writer

언어·프레임워크에 상관없이 **변경된 코드와 그 영향 범위**에 대해 올바른 테스트를 작성·실행하고, 실패 시 원인과 개선점을 피드백하는 [Claude Code](https://claude.com/claude-code) 스킬입니다. 기능 테스트뿐 아니라 **보안 안정성** 케이스도 함께 점검합니다.

## ✨ 무엇을 하나

- **변경분 기반 작성** — `git diff`로 방금 수정/추가한 코드(로직만)를 찾아 테스트를 붙입니다. 파일·함수를 직접 지정할 수도 있습니다.
- **영향 범위까지 실행** — 새로 쓴 테스트 + 관련 기존 테스트를 함께 돌려 회귀(기존 깨짐)를 확인합니다.
- **실패 시 피드백** — 실패를 *테스트 오류*인지 *코드 버그*인지 구분하고, 올바른 개선 방향을 알려줍니다.
- **보안 점검** — 인젝션(SQL/명령/경로 탐색/XSS), 인증·인가 경계, 민감정보 노출, 자원 한계(DoS) 등을 테스트로 검증합니다.
- **언어 독립** — 프레임워크를 하드코딩하지 않고, 프로젝트가 이미 쓰는 도구·스타일을 읽어 거기에 맞춥니다 (pytest, jest/vitest, JUnit, go test, cargo test, RSpec 등).

## 📦 설치

스킬은 `SKILL.md`가 든 폴더를 Claude Code가 읽는 위치에 두면 됩니다. 두 가지 방법이 있습니다.

### 방법 1. 개인 전역 설치 (내 모든 프로젝트에서 사용)

```bash
npx skills add dahun428-fx/work_tools --skill test-writer -g -a claude-code -y
```

이러면 어느 프로젝트에서든 이 스킬이 활성화됩니다. 업데이트는 `npx skills update test-writer -g`.

### 방법 2. 팀 레포에 포함 (그 레포에서 팀 전체 공유) — 권장

공유하려는 프로젝트 레포 안에 넣고 커밋하면, 팀원은 `git pull`만 하면 자동으로 쓸 수 있습니다.

```bash
# 프로젝트 루트에서
npx skills add dahun428-fx/work_tools --skill test-writer -a claude-code -y   # -g 없이 실행하면 프로젝트의 .claude/skills/ 에 설치
git add .claude/skills/test-writer
git commit -m "chore: test-writer 스킬 추가"
git push
```

> 두 방법 다 핵심은 **`.../skills/test-writer/SKILL.md`** 경로가 존재하는 것입니다.

설치 후 Claude Code 세션을 새로 시작하면 스킬이 인식됩니다.

## 🚀 사용법

자연어로 테스트를 요청하면 자동으로 발동합니다. 프레임워크를 명시할 필요 없습니다.

```
# 방금 작업한 변경분에 대해
"방금 바꾼 거 테스트 짜줘"

# 특정 대상 지정
"src/payment/discount.py 의 apply_discount 테스트 작성해줘"

# 보안까지
"이 로그인 핸들러 테스트 짜줘, 보안적으로 안전한지도 확인해줘"

# 커버리지 보강
"order 모듈 테스트 보강해줘"
```

명시적으로 호출하려면:

```
/test-writer
```

### 동작 흐름

1. **환경 감지** — 언어·테스트 프레임워크·실행 명령을 파악하고 기존 테스트 스타일을 학습
2. **대상 결정** — 변경분(또는 지정 대상) + 영향 범위를 식별하고 목록을 먼저 보여줌
3. **케이스 도출** — 정상/경계/에러 + 보안 케이스
4. **작성** — 프로젝트 컨벤션 그대로 (AAA 구조, 서술형 이름)
5. **실행·피드백** — 새 테스트 + 관련 기존 테스트를 돌리고, 실패하면 원인·개선점 보고

### 실패 피드백 예시

```
❌ 실패: test_빈_장바구니_결제시_에러
원인: 빈 장바구니 입력 시 에러 대신 0원 결제가 진행됨 (기대: ValueError, 실제: 정상 반환)
판단: 코드 버그
개선점: checkout() 진입부에서 items 비어있으면 ValueError를 던지도록 가드 추가
```

## ✅ 요구사항

- 프로젝트의 테스트 프레임워크 (없으면 표준 프레임워크를 제안)
